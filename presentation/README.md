# Presentation

Course defense deck for **AI Sales Manager**.

| File                                               | Use                                                                        |
| -------------------------------------------------- | -------------------------------------------------------------------------- |
| [`AI-Sales-Manager.pptx`](./AI-Sales-Manager.pptx) | Open in PowerPoint or Google Slides for the oral defense                   |
| [`index.html`](./index.html)                       | Open in a browser for a full-screen walkthrough (arrow keys, space, swipe) |

Regenerate the PowerPoint after edits:

```bash
python presentation/build_pptx.py
```

The deck covers the problem, MVP, architecture, product surfaces, Derja AI behaviour, testing numbers (including Asma’s whole-app account), measured refactoring, the demo video, team ownership (`docs/06-ethics` for Aymen), and how to run the app.

## How this maps to the course

| Course chapter                                           | Product question we answer                                                            |
| -------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| Kantian ethics (categorical imperative, humanity as end) | Would we accept a maxim that invents prices or never escalates a distressed customer? |
| Virtue ethics (character, practical wisdom)              | Which habits does the system reward in merchants, agents, and the development team?   |

Ethics is not a separate “slide of good intentions.” It is enforced in code (commercial guardrails, approval mode, handoff triggers), measured in tests (golden commercial-safety gate = 0%), and reviewed in this reflection.
